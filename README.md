# Early Academic Risk Detection System

## Overview

This project uses Machine Learning to identify students who may be at risk of academic underperformance based on demographic and educational indicators.

The system analyzes factors such as parental education, lunch type, gender, race/ethnicity, and test preparation status to classify students into High Risk, Medium Risk, and Low Risk categories.

In addition to prediction, the project generates personalized recommendations that can help students improve their academic outcomes.

## Dataset

Dataset: Students Performance in Exams (Kaggle)

Records: 1000 students

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn

## Key Findings

* Students completing test preparation courses scored significantly higher on average.
* Students with standard lunch showed higher academic performance than students receiving free/reduced lunch.
* Parental education emerged as one of the strongest predictors of academic performance.
* Using demographic and educational indicators achieved approximately 44.5% prediction accuracy.
